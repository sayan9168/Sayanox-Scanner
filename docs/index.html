Multi-Profile Scanning

Common (Top 20), Well-Known (1–1023), Registered, Full (1–65535), and fully custom ranges.

⚡

Real-time Metrics

Live ports/sec rate, elapsed time, neon progress bar, and open/closed counters updating as you scan.

◎

Service Hints + Latency

Automatic service detection (SSH, HTTP, MySQL, RDP, Redis…) with millisecond latency for every open port.

Cyber-Neon UI

Pure dark theme with cyan / magenta / green accents and monospace typography built for focus.

Concurrent Engine

Semaphore-limited parallel TCP connect scans. Configurable timeout and concurrency. Cancel anytime.

Zero Root

Pure Java sockets. Works on any Android 8.0+ device without special privileges or binaries.
